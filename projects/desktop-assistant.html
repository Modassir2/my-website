Why it exists

I wanted a second pair of hands that could drive the desktop without a heavy GUI. Something that opens in a terminal, sees a screenshot, and does one useful thing. Not another chat window pretending to be an operating system.

A lightweight, terminal-based (TUI) desktop assistant designed for speed and efficiency.

README.md · Desktop Assistant

What it does

01

A real terminal UI

Rich output, structured data, and a prompt that stays out of the way. No browser process required.

02

100% local support

Tested against LM Studio, Ollama, and llama.cpp's OpenAI-compatible server. Cloud endpoints work too.

03

Image-aware context

Screenshots are part of the conversation. Token budgets decide how many images stay in history.

04

Keyboard driven

No mouse-hunting through menus. Type, run, inspect the result, move on.

Choosing a model

The README is opinionated here, which I like. It suggests looking at UI-grounding benchmarks such as ScreenSpot and OSWorld, and aiming for 75%+ before expecting good results. The recommendation is the largest Qwen3-VL model that fits, with a floor of 4B.

For low-end hardware, the tested setup is Qwen3-VL 4B at Q4_K_M, with an mmproj at Q8_0 rather than BF16. A shortened version of the server command: 

llama-server.exe ^
  --model Qwen3-VL-4B-Instruct-Q4_K_M.gguf ^
  --mmproj mmproj-Qwen3-VL-4B-Instruct-q8_0.gguf ^
  --flash-attn on ^
  --ctx-size 8192 ^
  --host 0.0.0.0 --port 8002 ^
  --parallel 1 -ctv q8_0 -ctk q8_0
Windows note: the ^ characters are line continuations in cmd. In PowerShell, use a backtick or put the command on one line.

Configuration

SettingWhat it controls
base_urlThe OpenAI-compatible endpoint. LM Studio, Ollama, Groq, OpenRouter, xAI, Gemini, or OpenAI.
api_keyRequired for paid platforms. Local models usually ignore it, so a placeholder is fine.
image_tokensHow many tokens one image consumes when the history is trimmed. Default is 1105.
max_tokensThe context window of the endpoint. 8192 is the tested minimum.
last_n_imagesHow many recent screenshots stay visible in history. The README recommends at least 3.
width / heightMonitor resolution used to turn model coordinates into real click positions.

What the README says

The repository describes it as:

  • Rich terminal UI with pretty-printed console output
  • Local AI support tested on LM Studio, Ollama, and llama.cpp
  • Keyboard-driven commands without leaving the terminal
  • Lightweight, with no heavy GUI overhead

It also includes a practical warning about model choice: image support and reliable tool calling are not optional here. A model that cannot ground a click is not going to drive a desktop.
