02 — Side projects

The experiments.

No repo, no landing page. These are things I wanted to understand, or things that needed to exist in my own setup.

01 · Local infrastructure

A model server I actually run

llama.cpp in router mode on port 8002, with six model presets and on-demand loading. Gemma and Qwen builds share one OpenAI-compatible endpoint without restarting the server. This is what Infinity and most of my experiments talk to.

llama.cpp Router mode 6 presets OpenAI-compatible
02 · Fine-tune

Gemma 3 1B, on 4 GB of VRAM

Fine-tuned a small Gemma 3 1B model using Unsloth's memory-optimized training to mimic the way I text on WhatsApp. Tight hardware, small model, surprisingly recognisable results.

Unsloth Gemma 3 LoRA 4 GB VRAM
03 · Vision

Teaching a model to see a screen

Trained YOLO and DETR-family models for hand detection, face recognition, and classifying UI objects on a screen. The screen-object work was the groundwork for giving an assistant eyes.

YOLO RT-DETR OpenCV UI grounding
04 · Foundations

A neural network, from scratch

A small neural network written in plain Python and trained on the classic MNIST handwritten digits dataset. Built to make sure I understood the maths instead of importing it.

Python MNIST Backpropagation
05 · Homelab

The network in my room

Pi-hole for network-wide DNS blocking, a self-hosted SearXNG search engine, Tailscale for a mesh VPN, Playit.gg for a Minecraft Java server, and a Flask app or two. Most of it runs through Arch inside WSL, which is where I learned the most.

Pi-hole SearXNG Tailscale WSL / Arch Flask
