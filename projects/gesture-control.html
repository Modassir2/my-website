Why it exists

After building assistants that could see a screen, I wanted to see if my hand could become an input device without buying anything new. A webcam was already on the desk. MediaPipe already knew where the joints were. The missing part was mapping gestures to mouse actions in a way that did not feel like fighting a laggy touchpad.

A Windows desktop mouse controller that uses a webcam and MediaPipe hand tracking to translate hand gestures into mouse movement, clicks, scrolling, and drag-and-drop control.

The gesture map

Gestures are recognised in the order defined in gestures.py. Pinches take priority, so avoid making several fingertips touch at once.

GestureAction
Index + middle open; ring + pinky curledMove the mouse
Thumb + index pinchLeft click
Thumb + middle pinchRight click
Index, middle, pinky open; ring curledVertical scroll
Index, ring, pinky open; middle curledToggle drag-and-drop hold
Index, middle, ring open; pinky curledMiddle click
KeyAction
q / EscQuit
p / SpacePause until another key is pressed
rReload config.json without restarting

How it works

  1. Track the hand.

    MediaPipe's hand landmarker returns 21 points per hand from the webcam feed, with confidence, presence, and tracking thresholds set in the config.

  2. Read the gesture.

    Finger states are compared against the gesture rules. Pinches are detected by fingertip distance, with a threshold and a click cooldown to prevent double-clicks.

  3. Smooth the movement.

    The index fingertip anchors the cursor. A deadzone stops jitter, a smoothing factor softens motion, and a sensitivity multiplier maps camera distance to screen distance.

  4. Drive the mouse.

    PyAutoGUI handles movement, clicks, scrolls, and the held-button state for drag and drop. The preview window shows landmarks, gesture status, confidence, and FPS.

  "TOUCH_THRESHOLD": 25,
  "SENSITIVITY": 10.8,

Running it

The repository is Windows-first and needs Python 3.9+, a webcam, and a display that PyAutoGUI can control. The hand landmarker model is downloaded separately. 

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python download_handmarker.py
.\run.bat

The preview window opens as MediaPipe Gesture Controller. If the camera is not detected, change CAMERA_ID from 0 to 1 or 2.

What the README says

The project lists these capabilities:

  • Move the mouse with a two-finger gesture
  • Left, right, and middle click with pinch or finger gestures
  • Scroll vertically using the index and middle fingers
  • Toggle a held mouse button for drag-and-drop operations
  • Display hand landmarks, gesture status, confidence, and FPS in a live preview
